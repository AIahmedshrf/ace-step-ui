# دليل الواجهة الخلفية (Backend API) - المنافذ والمسارات

## فهم هيكل الخدمات

المشروع يتكون من **3 خدمات مستقلة** تعمل على منافذ مختلفة:

| الخدمة | المنفذ | الغرض |
|---|---|---|
| **الواجهة الأمامية** (Vite/React) | `3000` | واجهة المستخدم - هذا ما يُفتح في المتصفح |
| **الواجهة الخلفية** (Node.js API) | `3001` | API server - للتواصل البرمجي فقط |
| **ACE-Step API** (Python/FastAPI) | `8001` | محرك توليد الموسيقى بالذكاء الاصطناعي |

---

## لماذا تظهر "Cannot GET /" عند فتح :3001 ؟

هذا **طبيعي تمامًا وليس خطأ**.

الواجهة الخلفية على المنفذ `3001` هي **API Server** (خادم برمجي)، وليس موقع ويب عادي.
لا يوجد مسار للصفحة الرئيسية `/` لأنه لم يُصمم ليُفتح مباشرة في المتصفح.

**العناوين الصحيحة للتحقق من الخلفية:**

```
http://localhost:3001/health          ← فحص الحالة (يجب أن يرجع JSON)
http://localhost:3001/api/auth/auto   ← اختبار تسجيل الدخول التلقائي
```

## نظام المصادقة

### هذا تطبيق محلي أحادي المستخدم

**لا توجد كلمة مرور admin** — النظام مصمم للاستخدام المحلي الشخصي.

### كيف يعمل:

1. **أول تشغيل:** الواجهة الأمامية تستدعي `GET /api/auth/auto`
   - إذا لم يوجد مستخدم → تظهر نافذة لإدخال اسم المستخدم
   - إذا وُجد مستخدم → تسجيل دخول تلقائي

2. **إنشاء المستخدم:** `POST /api/auth/setup` مع `{ "username": "اسمك" }`
   - يُنشئ المستخدم في قاعدة البيانات المحلية (SQLite)
   - يُرجع JWT token صالح لمدة 365 يومًا

3. **الطلبات التالية:** تُرسَل مع header:
   ```
   Authorization: Bearer <token>
   ```

### اختبار المصادقة يدويًا (curl):

```bash
# الخطوة 1: إنشاء مستخدم
curl -X POST http://localhost:3001/api/auth/setup \
  -H "Content-Type: application/json" \
  -d '{"username": "myname"}'

# الاستجابة المتوقعة:
# {"user": {"id": "...", "username": "myname", ...}, "token": "eyJ..."}

# الخطوة 2: استخدام الـ token
curl http://localhost:3001/api/songs/my \
  -H "Authorization: Bearer <TOKEN_FROM_STEP_1>"
```

### تسجيل الدخول التلقائي:

```bash
curl http://localhost:3001/api/auth/auto
# إذا يوجد مستخدم: يرجع user + token تلقائيًا
# إذا لا يوجد: يرجع 404 → الواجهة تطلب اسم مستخدم
```

## ملاحظة مهمة حول الدخول للتطبيق

**لا تفتح http://localhost:3001 مباشرة.**

افتح دائمًا: **http://localhost:3000**

الواجهة الأمامية (port 3000) تتواصل تلقائيًا مع الخلفية (port 3001) في الخلفية.
في أول تشغيل ستظهر نافذة لإدخال اسم مستخدم — أدخل أي اسم تريده (بدون كلمة مرور).
